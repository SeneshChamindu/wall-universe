# 🌌 Wall Universe

**Discover your next wallpaper.**

Wall Universe is a mobile-friendly wallpaper platform designed to help users discover, save, and download high-quality wallpapers.

## ✨ Features

* 📱 Mobile-friendly, responsive design
* 🌙 Dark and light themes
* 🔍 Wallpaper search
* 🗂️ Wallpaper categories
* ❤️ Favorites and collections
* 🔐 User authentication
* 🛡️ Admin-only wallpaper uploads
* 📲 Progressive Web App (PWA) support
* ☁️ Supabase integration

## 🛠️ Technologies

* React
* Vite
* Supabase
* CSS
* Lucide React
